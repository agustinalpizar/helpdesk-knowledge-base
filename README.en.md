# Knowledge Base — IT Support Tickets (Help Desk L1)

[🇪🇸 Versión en español](./README.md)

18 simulated Level 1 Help Desk tickets, each written the way a real user would report an issue, followed by a step-by-step diagnostic process and the solution applied. The goal is to document the troubleshooting reasoning, not just the fix.

**Categories covered:** Networking, Printers, Accounts/Access (Active Directory), Hardware, Software.

> All cases are simulated for portfolio purposes. The diagnostic methods and tools referenced (Active Directory, Device Manager, Event Viewer, `ping`/`ipconfig`, etc.) reflect real knowledge applied in personal labs and freelance technical support — see profile below.

The ticket files are written in Spanish, since that is the working language of the environment they simulate. The index below gives the English title of each case so the content is navigable either way; commands, error codes and tool names are identical in both languages.
